# Minecraft update artwork

Official Tricky Trials artwork for Java Edition 1.21 and 1.21.1, downloaded from
[Minecraft's Tricky Trials page](https://www.minecraft.net/en-us/updates/tricky-trials).

- Banner: https://www.minecraft.net/content/dam/minecraftnet/games/minecraft/key-art/Tricky-Trials_Full-Bleed-A-1200_Key-art_2880x1080.jpg
- Tile: https://www.minecraft.net/content/dam/minecraftnet/games/minecraft/key-art/Tricky-Trials_Full-Bleed-A-0_Key-art_786x786_01.jpg

Minecraft artwork belongs to Mojang/Microsoft and is not covered by this project's MIT license.
The app uses built-in pack covers by default. For optional offline artwork,
save both images next to this file as `tricky-trials-banner.jpg` and
`tricky-trials-tile.jpg` before building.
